Technical Architecture

How Deepfake Detection Works

An in-depth look into the 8-stage automated pipeline that transforms raw media files into authenticated biometric forensic verdicts.

1
1. Upload Media

The user securely submits an image (JPG, PNG) or video (MP4, AVI, MOV) through the drag-and-drop web interface.

2
2. Validate File

Server-side validation confirms file integrity, size threshold (up to 50MB), MIME types, and header security to prevent malformed inputs.

3
3. Preprocess Media

Image bytes are decoded via cv2.imdecode() for reliable reading. For videos, keyframes are sampled evenly across the timeline.

4
4. Extract Frames

Evenly distributed keyframes are sampled across the video timeline to capture temporal variations and inter-frame transitions.

5
5. Detect Face

OpenCV 5 YuNet AI (FaceDetectorYN) scans for faces via deep neural network. If nothing found, a relaxed-threshold retry runs automatically as a robust fallback.

6
6. AI Analysis

Cropped face matrices (224×224, normalized [0,1]) analyzed by CNN layers and 2D Fourier frequency filters to detect GAN micro-texture anomalies and blending artifacts.

7
7. Generate Result

The classification head produces Real vs Fake probability scores, issuing a final verdict — REAL, DEEPFAKE, or ANALYSIS INCONCLUSIVE — with a confidence percentage.

8
8. Save Detection

Results, forensic telemetry, and face preview saved to the user's account. A downloadable ReportLab PDF forensic certificate is generated instantly.

Detection Pipeline — Decision Flow

1
Upload & Validate

Extension (JPG/PNG/MP4/AVI/MOV), size ≤ 50 MB, and pixel integrity verified using PIL before any processing begins.

2
Convert & Read Image

Image bytes decoded via cv2.imdecode() — bypasses Windows Unicode path issues common with cv2.imread().

3
YuNet Face Detection (OpenCV 5)

FaceDetectorYN neural network runs at confidence threshold 0.55. If no face found, automatic retry at 0.35 provides a robust second pass.

YES
Face Found → Crop → Resize 224×224 → Normalize

Primary face cropped with 15% padding, resized to 224×224 px, normalized to [0, 1] float — ready for model input.

NO
Both Passes Failed → Analysis Inconclusive

No verdict assigned without a confirmed face. System returns Analysis Inconclusive — confidence shown as N/A, never a fabricated score.

AI
Deepfake Model Inference

If deepfake_model.h5 is present: Keras CNN inference. Otherwise: CV Forensic Engine using Laplacian sharpness variance + FFT frequency energy + YCbCr Chroma disparity.

✓
Verdict + Confidence Score + PDF Report

REAL ✓ or DEEPFAKE ✕ — with confidence %, Real/Fake probability scores, and a downloadable forensic PDF certificate.
